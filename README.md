# Gestion des tâches – Application Python (console)

Projet réalisé dans le module **Outils collaboratifs avec Git / GitHub** (Licence 1, S1).

**Binôme :** Med Melek Boukeri – Mohamed Mchit

## Description
Petite application Python en mode console qui permet de gérer des tâches quotidiennes.
Tout le code se trouve dans un seul fichier : `main.py`.

## Fonctionnalités
- **1 – Ajouter une tâche** : demande un titre, refuse une saisie vide.
- **2 – Afficher les tâches** : liste numérotée, message si la liste est vide.
- **3 – Rechercher une tâche** : recherche d'un mot-clé dans les titres.
- **0 – Quitter** : ferme le programme (toute autre option affiche une erreur).

## Étapes réalisées
1. Création du dossier du projet et du fichier `main.py` dans VS Code.
2. Test du programme avec « Run Python File ».
3. Rédaction du `README.md`.
4. Ajout de la recherche de tâches.
5. Initialisation de Git, trois commits minimum, création du dépôt GitHub et premier `git push`.
6. Amélioration du code, nouveau commit et second `git push`.

## Exécution
1. Ouvrir le dossier du projet dans **VS Code**.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **« Run Python File »** (triangle en haut à droite).
4. Utiliser le menu dans le terminal.
